## About this edition

September 26, 2026 is a focused evidence and editorial update, not a new run of every underlying model. The data-center report distinguishes global electricity projections from local bill outcomes and corrects the interpretation of overlapping scenario weights. The jobs report adds eight recommendations for ownership and transitions, alongside dated labor-market observations. Neither report establishes a calibrated crash date, stock-selection strategy or national AI job-loss forecast.
